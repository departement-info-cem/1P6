## Besoin : la méthode doit retourner true si le nombre est positif et false sinon. Le code proposé répond-il au besoin ?

```csharp
static bool EstPositif(int nombre)
{
    return false;

    if (nombre > 0)
    {
        return true;
    }
}
```

- [ ] Oui, car le if vérifie si le nombre est positif.
- [x] Non, car return false termine la méthode avant l'exécution du if.
- [ ] Non, car une méthode bool ne peut avoir qu'un seul return.
- [ ] Non, car return doit toujours être placé à la fin.

## Besoin : la méthode doit retourner true si le nombre est pair et false sinon. Le code proposé répond-il au besoin ?

```csharp
static bool EstPair(int nombre)
{
    return nombre % 2 == 0;
}
```

- [x] Oui, car l'expression nombre % 2 == 0 produit directement une valeur booléenne.
- [ ] Non, car il faut utiliser un if pour retourner true ou false.
- [ ] Non, car l'opérateur % ne peut pas être utilisé avec une méthode bool.
- [ ] Non, car la méthode devrait retourner un int.
