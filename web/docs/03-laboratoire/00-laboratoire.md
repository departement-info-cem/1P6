# 🧪 Progression des exercices



Les exercices de chaque laboratoire sont organisés selon quatre niveaux de progression. L'objectif est de vous permettre de développer graduellement votre compréhension des concepts et votre autonomie en résolution de problèmes.

Chaque niveau correspond à ce qui est attendu de vous lors de la réalisation des exercices.

## 🟢 Comprendre

> 🧠 **Je comprends** : je peux lire, interpréter et expliquer un programme simple.

> ⚠️ Ces exercices doivent être réalisés sans utiliser l'ordinateur.
N'ouvrez pas Visual Studio pour écrire et exécutez le code. L'objectif est de développer votre capacité à comprendre et à analyser le code par vous-même.

À ce niveau, l'objectif est de vérifier votre compréhension des notions vues en classe.

Vous pourriez être amené à :

* déterminer le contenu d'une variable après l'exécution d'un programme;
* prédire ce qui sera affiché à l'écran;
* interpréter le comportement d'un extrait de code;
* identifier une erreur simple;
* compléter quelques lignes dans un programme fortement guidé.

L'accent est mis sur la compréhension du code plutôt que sur son écriture.


---

## 🔵 Appliquer

> ⚙️ **J'applique** : je peux utiliser une notion dans une situation similaire aux exemples vus en classe.

À ce niveau, vous commencez à écrire du code en vous appuyant sur les démarches déjà présentées.

Vous pourriez être amené à :

* compléter un programme partiellement fourni;
* adapter un exemple vu en classe;
* utiliser correctement des variables, des expressions ou des instructions déjà étudiées;
* produire un programme en suivant des consignes détaillées.

L'objectif est de mettre en pratique les notions dans un contexte familier.

---

## 🟣 Résoudre

> 🧩 **Je résous** : je peux analyser un problème et construire moi-même une solution.

À ce niveau, moins d'indications sont fournies. Vous devez déterminer les étapes nécessaires pour atteindre l'objectif demandé.

Vous pourriez être amené à :

* choisir les variables à utiliser;
* déterminer les calculs ou les traitements à effectuer;
* organiser les instructions dans le bon ordre;
* développer une solution complète à partir d'un énoncé.

L'objectif est de développer votre autonomie en programmation.

---

## ⚫ Défi

> 🚀 **Je relève un défi** : je peux résoudre un problème plus complexe ou moins guidé en combinant plusieurs notions.

À ce niveau, vous devez faire preuve d'initiative et mobiliser l'ensemble des connaissances acquises.

Vous pourriez être amené à :

* analyser une situation nouvelle;
* combiner plusieurs concepts dans une même solution;
* prendre des décisions de conception;
* élaborer une solution à partir d'un énoncé plus ouvert.


> L'objectif est de consolider vos acquis et de vous préparer à résoudre des problèmes de programmation de façon autonome.

# 💡 Conseil

Si vous êtes bloqué dans un exercice 🟣 **Je résous**, ne cherchez pas immédiatement une solution sur Internet ou auprès d'une IA.

Revenez aux exercices 🟢 **Je comprends** et 🔵 **J'applique** du laboratoire. Ils contiennent les notions, les exemples et les démarches nécessaires pour vous aider à construire votre propre solution.

Prenez le temps d'analyser le problème, d'identifier les données à manipuler et de décomposer la solution en petites étapes. Cette démarche fait partie intégrante de l'apprentissage de la programmation.

> **Le but n'est pas seulement de terminer l'exercice. Le but est de devenir capable de résoudre le prochain exercice avec de moins en moins d'aide.**
